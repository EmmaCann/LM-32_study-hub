## Una risorsa, un proprietario

**Resource Acquisition Is Initialization** associa la gestione di una risorsa al lifetime di un oggetto. Il costruttore acquisisce la risorsa; il distruttore la rilascia.

Questo modello si applica alla memoria, ma anche a file, mutex e altri handle. In presenza di eccezioni, lo stack unwinding distrugge gli oggetti automatici già costruiti.

## Un esempio con un file

```cpp
#include <fstream>
#include <stdexcept>

void salva() {
    std::ofstream file("appunti.txt");
    if (!file) throw std::runtime_error("Apertura fallita");
    file << "Un concetto alla volta";
} // Il distruttore di ofstream chiude il file.
```

## Cosa garantisce e cosa no

RAII evita di dover ricordare il rilascio manuale lungo ogni percorso di uscita ordinario o per eccezione. Non sostituisce il controllo degli errori di I/O e non garantisce distruttori eseguiti in caso di terminazione forzata del processo.

> Preferisci oggetti che rappresentano esplicitamente l’ownership. Il prossimo esempio usa [std::unique_ptr](/cpp/gestione-memoria/smart-pointer).
